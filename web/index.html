On iOS 9, tap a track’s download action. Safari may open the audio instead of saving it; use an available Open In / share option if shown. Downloads do not become a managed offline Spotlight library.

A FEW DETAILS

Settings

Spotlight serves the music folder configured on the laptop. Use Start-Spotlight.bat or run python server.py --music "D:\Music".

For iOS 9, use MP3 (or AAC/M4A) and classic Safari controls. The interface uses ES5 JavaScript, no modules, and conservative CSS. Physical iPad mini testing is required to confirm your library’s actual files and Wi-Fi setup.

Downloads use the browser’s normal file handling. iOS 9 predates Safari’s download manager and the download attribute; no arbitrary folder or permanent offline storage is promised.
